# Privacy Policy

**Football Logo Downloader v2.x**

Football Logo Downloader is designed to work without an account, API key or telemetry service.

## Data Collected by the Application

The application itself does **not** collect, transmit or sell personal information to the developer.

It does not include:

- analytics or advertising SDKs;
- user accounts or sign-in;
- telemetry reporting;
- crash-reporting services;
- tracking identifiers;
- advertising profiles.

## Local Settings

To remember user preferences, the application stores a small local settings file under the current Windows user's local application data directory:

```text
%LOCALAPPDATA%\FootballLogoDownloader\settings.json
```

The settings may contain:

- selected language;
- selected appearance mode;
- selected output folder;
- most recently selected country and competition.

These settings remain on the user's computer and are not sent to the developer.

## Network Requests

The application connects to **FootyLogos.com** over HTTPS to retrieve country, competition and logo data requested by the user.

Those requests are made directly from the user's computer to FootyLogos. Any server-side logging performed by FootyLogos is governed by FootyLogos' own policies and is outside this project's control.

When users download Football Logo Downloader from GitHub, GitHub may process access and download information under GitHub's own privacy policies. The application itself does not receive that information.

## Downloaded Files

Logo files are saved only to the folder selected by the user. The application does not upload files from the user's computer.

## Changes

Material privacy-related changes will be documented in the repository and, where appropriate, in release notes.

## Contact

Questions about this policy can be raised through the project's GitHub repository.
